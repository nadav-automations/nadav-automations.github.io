A small internal feedback tool built on Google Sheets

What it is

AI Order Processing Feedback is a Google Sheets script used by a small private team to log feedback on an order processing app: bugs, AI errors, suggested improvements and feature requests.

It is not a public service. Only people the sheet's owner adds to the team can use it.

What it does

  • Adds an Actions menu and pop-up windows to the feedback spreadsheet for adding, editing and deleting entries.
  • Stamps each entry with an ID, date and priority, and stops people editing each other's entries.
  • Saves screenshots that team members attach to an entry in a shared Google Drive folder that the tool creates.
  • Emails lists of entries and summaries to the people the user chooses, including an optional weekly summary.

Why it asks for permissions

The tool only uses what it needs to run inside the feedback spreadsheet. It can only see Google Drive files that it created itself or that the user picks in Google's own file picker. The privacy policy lists each permission and why it is needed.
